### Global Rules (from DESIGN.md)
- **NO 1px divider lines.** Separate sections via background shifts, white space, or card mass.
- **NO color** except grayscale + `error` (#ba1a1a) sparingly.
- **NO sharp corners.** Every interactive element must be rounded (minimum `rounded-2xl`; buttons/chips use `rounded-full`).
- **NO thin font weights.** Never use `font-light`; minimum `font-normal` (400), prefer `font-medium`/`font-bold`/`font-black`.
- Cards: white (`surface-container-lowest`) on light grey (`surface`) background with soft ambient shadow: `box-shadow: 0 4px 24px rgba(0,0,0,0.04)`.
- Progress bars/circles: thick stroke (8-12px), track = `surface-container-highest`, fill = gradient `primary` → `primary-container`.
- Buttons: **Primary** = solid black fill, `on-primary` text, `rounded-full`. **Secondary** = 2px black border, transparent bg. **Tertiary** = bold text only.
- Input fields: `surface-container-highest` background, `rounded-xl`, no bottom-line. On focus: white bg + 2px black border.

## Implementation Notes

1. **Mobile viewport:** All screens max-width `390px`, centered on desktop (`mx-auto`). Add `min-h-screen bg-surface` to root.
2. **Scrollable content:** Each page has `pb-24` bottom padding to clear the fixed bottom nav.
3. **Icons:** Load Material Symbols via `<link>` in `index.html`. Use as `<span className="material-symbols-outlined">icon_name</span>`.
4. **No dividers rule:** Between list items use `space-y-4` or `space-y-5` only. Never `<hr>` or `border-b`.
5. **Shadows:** Cards use `shadow-[0_4px_24px_rgba(0,0,0,0.04)]` (add as custom utility or inline style).
6. **Progress bars:** `rounded-full` track div + inner fill div. Black fill.
7. **Circular progress (Profile goals):** Use inline SVG `<circle>` with `stroke-dasharray` / `stroke-dashoffset` calculated from percentage.
8. **Recharts (Analytics):** Disable grid (`<CartesianGrid>` omit or `strokeOpacity={0}`), use custom dot={false}, stroke="black", strokeWidth={2}.
9. **Toggle switches (Focus screen):** Implement as styled `<button>` with state. Pill shape, black when ON.
10. **All dummy data hardcoded** — no backend needed.
