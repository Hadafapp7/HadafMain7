Fix icons + add animations to the Hadaf app (Expo Go / React Native)
Problem 1 — Icons show Chinese characters in Expo Go
Root cause: Material Symbols Outlined is a web font loaded via Google CDN <link> tag. React Native (Expo Go) cannot use web fonts for icon rendering — it falls back to system CJK glyphs.
Fix: Replace Material Symbols with @expo/vector-icons

Install: npx expo install @expo/vector-icons
Import in every file that uses icons:

jsimport { MaterialIcons, MaterialCommunityIcons } from '@expo/vector-icons';

Replace every <span className="material-symbols-outlined">icon_name</span> with the equivalent @expo/vector-icons component. Use MaterialIcons first; fall back to MaterialCommunityIcons if not found. Reference mapping:

Remove all <link> tags referencing fonts.googleapis.com/css2?family=Material+Symbols from any HTML or web entry point. They have zero effect in React Native.

Problem 3 — Continuously moving 3D background animation
Add a subtle animated gradient mesh behind all screens. Use react-native-reanimated with a looping animation.
Install: npx expo install expo-linear-gradient
Implementation — AnimatedBackground.jsx
Create a component that renders 3–4 large blurred circles that drift slowly in different directions, creating a parallax depth illusion:
jsimport { useEffect } from 'react';
import Animated, {
  useSharedValue, useAnimatedStyle,
  withRepeat, withTiming, Easing, interpolate
} from 'react-native-reanimated';
import { View, StyleSheet, Dimensions } from 'react-native';

const { width, height } = Dimensions.get('window');

function FloatingOrb({ size, startX, startY, endX, endY, duration, color, delay }) {
  const progress = useSharedValue(0);
  useEffect(() => {
    progress.value = withDelay(delay, withRepeat(
      withTiming(1, { duration, easing: Easing.inOut(Easing.sin) }),
      -1, true  // infinite, reverse = true for back-and-forth
    ));
  }, []);
  const style = useAnimatedStyle(() => ({
    transform: [
      { translateX: interpolate(progress.value, [0, 1], [startX, endX]) },
      { translateY: interpolate(progress.value, [0, 1], [startY, endY]) },
      { scale: interpolate(progress.value, [0, 0.5, 1], [1, 1.08, 1]) },
    ],
    opacity: interpolate(progress.value, [0, 0.5, 1], [0.06, 0.10, 0.06]),
  }));
  return (
    <Animated.View style={[{
      position: 'absolute',
      width: size,
      height: size,
      borderRadius: size / 2,
      backgroundColor: color,
      filter: 'blur(60px)',  // use style.filter on web; on native use blurRadius in Image or expo-blur
    }, style]} />
  );
}

export default function AnimatedBackground() {
  return (
    <View style={StyleSheet.absoluteFill} pointerEvents="none">
      <FloatingOrb size={300} startX={-50}  startY={-50}  endX={30}   endY={80}   duration={7000} color="#000000" delay={0}    />
      <FloatingOrb size={250} startX={200}  startY={100}  endX={150}  endY={200}  duration={9000} color="#3b3b3b" delay={500}  />
      <FloatingOrb size={200} startX={50}   startY={400}  endX={120}  endY={320}  duration={6000} color="#5e5e5e" delay={1000} />
      <FloatingOrb size={280} startX={100}  startY={600}  endX={60}   endY={500}  duration={8000} color="#000000" delay={1500} />
    </View>
  );
}
